# Argument Extraction and Classification. Framework and Results

Based on the suggestions done previously, including article type tagging, addressing conceptual overlap, and identifying reasoning patterns, we want to propose another approach grounded in Walton's argumentation framework, which defines an argument as "a structured attempt to justify a claim (conclusion) by giving reasons (premises)." This definition aligns very well with our use case for argument extraction. Moreover, Walton provides a well defined argumentation scheme (aka reasoning patterns) that serve as templates for common types of arguments used in scientific contexts and other domains. As suggested in reference [1], we selected a five-category scheme set from Walton's framework to perform one initial test with the article “Protein Damage, Ageing and Age-Related Diseases”

The workflow followed three connected steps:

1. Argument Recognition and Extraction: Identify and extract conclusions and premises from documents.

2. Argument Classification: Categorize arguments using the five-category scheme set.

3. Argument Validation: Filter arguments to ensure alignment with Walton's definition.

These “reasoning patterns” are not standard categories in established argumentation taxonomies.
