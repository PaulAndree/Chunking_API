# CONTROLLED KNOWLEDGE

# From Company Model to Corpus

# 1 Model

Classes, fields and references of the company. The data model defines the consistency rules.

# 2 Instantiate

A generative procedure defined in advance fills the classes stage by stage, keeping the rules.

# 3 Check

Fields, values, dates, references and relations: derived from the model, plus business rules.

# 4 Ask

Define the questions over the graph: by type, hops and temporal reasoning, with the statements they need.

# 5 Prompt

Generate the prompt per document, pulling from the model and the statements the questions need.

# Write

Documents generated in a second pass that stores the span of every fact, with aliases, errata and noise added under control.
