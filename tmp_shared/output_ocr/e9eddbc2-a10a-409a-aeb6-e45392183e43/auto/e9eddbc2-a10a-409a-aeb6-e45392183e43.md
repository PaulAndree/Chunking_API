# Evidence for an Intermediate in DNA Synthesis Involving Pyrophosphate Exchange

A Possible Role in Fidelity

Philippe Lecomte†, Oliver P. Doubleday‡ and Miroslav Radman†

Département de Biologie Moléculaire Université Libre de Bruxelles 1640-Rhode-St-Genèse, Belgium

(Received 13 June 1985, and in revised form 31 January 1986)

The incorporation of exogenous deoxyribonucleotide monophates (dNMP) was measured under conditions of ongoing DNA synthesis, providing arguments for the existence of a $[ \mathbf { D N A } _ { n } \cdot \mathrm { d N M P } \cdot \mathbf { P P i } ]$ intermediate in the nucleotide incorporation step of DNA synthesis:

$$
\mathrm { D N A } _ { n } + \mathrm { d N T P } \overset { \alpha } { \underset { - \alpha } {  } } [ \mathrm { D N A } _ { n } \cdot \mathrm { d N M P } \cdot \mathrm { P P i } ] \underset { - \beta } { \overset { \beta } { \underset { \alpha + 1 } {  } } } \mathrm { D N A } _ { n + 1 } + \mathrm { P P i } .
$$

The existence of such an intermediate is suggested by an apparent exchange of both dNMP and pyrophosphate (PPi) moieties of the deoxyribonucleotide triphosphate (dNTP) substrate with exogenous molecules. Such exchange and the incorporation of exogenous dNMP into DNA, strictly require ongoing DNA synthesis, suggesting that the energy for exchange reactions is provided by the cleavage of dNTP substrate.

We propose that nucleotide selection during ongoing DNA synthesis results largely from the different relative rates of forward $( \beta )$ and backward $( - \alpha )$ reactions involving the $[ \mathrm { D N A } _ { n } \cdot \mathrm { d N M P } \cdot \mathrm { P P i } ]$ intermediate: the forward (incorporation) reaction is expected to predominate for the correct nucleotide, whereas the backward (abortive) reaction is expected to predominate for incorrect nucleotides.

# 1. Introduction

The accuracy of the DNA replication machinery is largely determined by the DNA polymerase. Polymerase fidelity, for all prokaryotic DNA polymerases tested and for some eukaryotic DNA polymerases, has been shown to be a function of two enzymatic activities: (1) nucleotide selection, which results in a misinsertion frequency of about $1 0 ^ { - 5 }$ incorrect bases per nucleotide incorporated; and (2) $\mathbf { 3 ^ { \prime } } \to \mathbf { 5 ^ { \prime } }$ exonuclease proofreading activity, which decreases the misincorporation frequency by another factor of 10 to 100 (for a review, see Loeb & Kunkel, 1982). Whereas the mechanism of exonuclease proofreading is fairly well understood, the molecular mechanism of nucleotide selection is obscure.

# 3. Results and Discussion

# (a) Incorporation of exogenous deoxyribonucleoside monophosphates during ongoing DNA synthesis

To test for the existence of a $[ \mathrm { D N A } _ { n } \cdot \mathrm { d N M P } \cdot \mathrm { P P i } ]$ intermediate prior to the establishment of the phosphodiester bond (Fig. 1, reaction 5), we attempted to exchange "resident" dNMP (derived from a dNTP substrate) with exogenous dNMP during a DNA synthesis reaction in vitro. In a series of experiments using $E$ coli DNA polymerase I or DNA polymerase $\boldsymbol { \mathfrak { z } }$ from Drosophila embryos, and either primed phage M13mp2 DNA or homopolymers as templates and high concentrations of exogenous dNMP or ddNMP, incorporation of exogenous dNMP and ddNMP during ongoing DNA synthesis was observed.

Figure 2 shows a polyacrylamide gel separation of the reaction products from polymerization reactions with primed M13mp2 template DNA, using ddNTPs (columns 6, 7, 8 and 9) and ddNMPs (columns 1, 2, 3 and 4) in the presence of radioactively labelled pools of normal dNTPs. It is clear that ddNMPs cause chain termination but, unlike ddNTPs, ddNMPs block chain elongation irrespective of base complementarity. Chain termination occurs at every nucleotide position, with some hot-spots. This chain termination is probably caused by terminal incorporation of ddNMPs, since all reactions in Figure 2 were terminated by a ten-minute incubation with excess dNTPs and fresh DNA polymerase I (see the legend to Fig. 2).

Chain termination by non-complementary ddNMPs was also observed on homopolymer templates.

Table I shows that 1 mM-ddTMP, but not I mMdTMP or 1 mM-ddTTP, inhibits the replication of primer poly(dC) templates, indicating that contamination of ddTMP by ddTTP cannot account for the observed incorporation of ddTMP. Stable terminal incorporation of $\mathbf { 3 ^ { \prime } }$ -ddNMP was suggested by the inability of the isolated phenolextracted product to act as a template-primer for further synthesis unless treated with an excess of exonuclease III (data not shown).

To demonstrate that stable incorporation also occurs at internal positions of newly synthesized chains, $2 ^ { \prime }$ -deoxyribonucleotide monophosphate substrates were used.

Table 2 shows that for DNA polymerase I and for DNA polymerase $\pmb { \alpha }$ ,incorporation of $[ ^ { 3 2 } \mathbf { P } ] \mathbf { d T M P }$ depends on the complementarity between dNTP and template (presumably reflecting the requirement for ongoing DNA synthesis) and not on the complementarity between the dNMP and template. The incorporation of dTMP in poly(dA)-directed synthesis occurs only in the presence of dTTP (data not shown). This experiment eliminated the possibility of eventual contaminating dTTP, which if present is expected to be incorporated opposite the poly(dA) template rather than misincorporated opposite the poly(dC) template. In order to confirm that dTMP was stably incorporated at internal positions in the newly synthesized chains, and linked to deoxyguanosine residues, nearestneighbour analysis was performed (Josse et al. 1961; see also Kornberg, 1980). By this method, $\mathbf { 3 } ^ { \prime }  – \bigl ( \mathbf { \sqrt { 3 2 } P } \bigr )$ -labelled mononucleotides are obtained from DNA in which $\mathrm { 5 ^ { \prime } } \mathrm { - } ( \mathrm { \mathsf { x } } \mathrm { - } ^ { 3 2 } \mathrm { P } )$ -labelled nucleotide substrates were incorporated. A relationship between PPi-exchange and dNMP incorporation is suggested by the fact that DNA polymerase $\beta$ and terminal deoxynucleotidyl transferase, both of which are devoid of PPi exchange activity (Kato et al., 1967; Chang & Bollum, 1973), do not incorporate dNMPs, where $E$ .coli DNA" polymerase III, T4 phage DNA polymerase and AMV reverse transcriptase, all of which show PPi exchange, do incorporate dNMPs (data not shown).

If this interpretation is correct, the energy liberated by the cleavage of dGTP may be transiently stored in the system so as to be available to support reactions with exogenous dNMP and PPi molecules. If so, processive action of DNA polymerase may stimulate, or be required for, both PPi exchange and dNMP incorporation. This suggestion is consistent with the non-processive reaction modes of DNA polymerase $\beta$ and terminal deoxyribonucleotide transferase (Chang, 1975). A positive correlation between the processivity of mammalian DNA polymerase $\pmb { \alpha }$ , $\beta$ and $\gamma$ and their fidelity in vitro (Kunkel, 1985) suggests that PPi exchange and dNMP incorporation reactions reflect the mechanism by which processivity contributes to fidelity.

# (c) Pyrophosphate exchange with non-complementary triphosphate substrates

If the dNTP substrates are cleaved by DNA polymerase (Fig. 1, reactions 1 and 2) with low discrimination, then a mechanism of achieving high fidelity at the incorporation step could involve the $[ \mathrm { D N A } _ { n } \cdot \mathrm { d N M P } \cdot \mathrm { P P \hat { i } } ]$ intermediate and either of the "abortive" reactions $( - 2$ or 3) of Figure 1. It has been shown that during DNÁ polymerase I and AMV reverse transcriptase polymerization reactions with poly $\mathbf { \Gamma } _ { \mathrm { d } ( \mathbf { A } , \mathbf { T } ) ] }$ , all four dNTPs undergo PPi exchange, but only dATP and dTTP are incorporated (Seal $\&$ Loeb, 1976), suggesting that nucleotide incorporation is a high fidelity process, whereas PPi exchange is a low fidelity process, i.e. the former requires correct base-pairing between the dNTP substrate and the template whereas the latter does not.

Thus, one is led to ask whether the PPi exchange performs, or reflects, a proofreading reaction? The results in Table 5 show that the two replicative enzymes, DNA polymerase III from $E$ coli and DNA polymerase $\pmb { \alpha }$ from HeLa cells, catalyse PPi exchange involving complementary dGTP and noncomplementary dATP and dTTP substrates with the pattern expected for a proofreading reaction: PPi exchange involying non-complementary substrates is at least $1 0 ^ { 3 }$ times more frequent than misincorporation. These results suggest that PPi exchange is associated with a proofreading activity. It is nevertheless possible that it is merely a "nonspecific" reaction unrelated to proofreading activity, because dTTP was equally or less subject to PPi exchange than dATP, and yet is less frequently misincorporated (see Table 5). Therefore, there is either a preselection step discriminating more effectively against $\mathrm { { C } } \cdot \mathrm { { T } }$ mispairing than against $\mathrm { C } \cdot \mathrm { A }$ mispairing, or the PPi exchange simply reflects the intrinsic substrate specificity of DNA polymerases. Identification of mutator or antimutator DNA polymerases, which are affected in their PPi exchange related activity, will be crucial in distinguishing between these possibilities. Analogous mutants were instrumental for establishing the proofreading role of the $\mathbf { 3 ^ { \prime } }  \mathbf { 5 ^ { \prime } }$ exonuclease (for a review, see Loeb $\&$ Kunkel, 1982). It appears unlikely that pyrophosphorolysis (reaction 7) could be responsible for a proofreading activity, since it was shown that pyrophosphorolysis does not occur on a $\mathbf { 3 ^ { \prime } }$ -terminal mismatch (Chang & Bollum, 1973).

# (d) Rate of DNA synthesis, error rates and pyrophosphate exchange

We have reported that the error frequency during DNA synthesis in vitro by DNA polymerase α is proportional to the rate of DNA synthesis (Radman et al., 1981). Therefore, the slow rate of DNA chain elongation in vivo in mammalian cells (roughly 100- fold slower than in $E$ coli (Edemberg & Huberman, 1975: Dube et al., 1979; Meyer & Simpson, 1970)) may contribute to increased accuracy.

Figure 4 shows that increasing the rate of DNA synthesis, catalysed by DNA polymerase α replicating primed poly(dC) template, by increasing concentrations of dNTP substrate, causes increased error rates (Fig. 4(a)) and decreased efficiency of PPi exchange, in particular PPi exchange of the incorrect dATP substrate (Fig. 4(b)). Since (1) this correlation between the rate of DNA synthesis and error rate does not exist in the presence of pyrophosphatase (PPase) (data not shown), and (2) similar experiments using DNA polymerase $\beta$ which is devoid of PPi exchange activity, do not reveal a significant correlation between fidelity and the rate of incorporation (Fig. 5), the fidelity of DNA polymerase $\pmb { \alpha }$ may be related to its capacity to exchange PPi. The fact that DNA polymerase $\beta$ replicates homopolymers (Fig. 5) and natural DNA templates with a lower fidelity than DNA polymerase $\pmb { \alpha }$ (see Loeb & Kunkel, 1982) is consistent with the hypothesis that the fidelity of any DNA polymerase may be related to its capacity to exchange PPi. Thus, formation of the phosphodiester bond (reaction 5) and PPi exchange-related reactions ("rejection" reactions $- 2$ and 3may be competing reactions. Because the nucleotide incorporation reaction is very sensitive to mispairing between the dNTP substrate and the template and the PPi exchange is not (Table 4), this competition should favour incorporation of the correct substrate and PPi exchange-related "rejection" reactions of the incorrect substrate In other words, the rejection of the incorrect dNMP residue from the $\mathrm { [ D \mathbf { \dot { N } } A \cdot \ d N M P \cdot \mathbf { P P i } ] }$ intermediate in the form of reconstituted dNTP could function as a proofreading mechanism in DNA synthesis prior to establishment of the phosphodiester bond.

# (e) Effects of pyrophosphatase and pyrophosphate on the fidelity of DNA synthesis in vitro

A prediction of the model described above is that when both the original PPi and exogenous PPi are depleted, the rejection mechanism at the level of the $[ \mathbf { D N A _ { n } } \cdot \mathbf { d N M P } \cdot \mathbf { P P i } ]$ intermediate may be inhibited. Such inhibition could result in an increased life time for the $[ \mathbf { D } \mathbf { N } \mathbf { A } _ { n } \cdot \mathbf { d } \mathbf { N } \mathbf { M } \mathbf { P } ]$ intermediate, even when the dNMP is noncomplementary to the template, leading to an increased misincorporation. In other words, depletion of PPi could be mutagenic. A weaker prediction (due to the uncertainty of the effective local concentration of PPi at the relevant site of DNA polymerase) is that the addition of exogenous PPi may be antimutagenic in vitro. # (f) Possible relevance to mutagenesis in vivo

Studies in vivo have shown that the inducible SOS mutator effect in $E$ . coli is due to increased misincorporation during DNA synthesis, rather than inhibition of the post-replicative mismatch correction (Caillet-Fauquet et al., 1984). Studies in vitro suggest that the absence or inhibition of the proofreading $\mathbf { 3 ^ { \prime } } \to \mathbf { 5 ^ { \prime } }$ exonuclease activity may be required (Villani et al., 1978; Schapper et al., 1983) but is not sufficient (Doubleday et al., 1981; Moore et al., 198l) to allow replication of certain noncoding DNA lesions. The stimulation by PPase of the "bypass" replication of AP sites both in $\phi \mathbf { X } 1 7 4 $ DNA (Doubleday et al., 1983) and with a defined oligonucleotide substrate (P. Lecomte & M. Goodman, unpublished results) suggest that a PPi exchange-associated proofreading activity of DNA polymerase may be the one rate-limiting step in the error-prone replication of AP sites. Hence the SOS mutator effect in E. coli may involve either induction of a PPase or the modification of the capacity of DNA polymerases to perform a proofreading reaction involving the pyrophosphate. Such a possibility is consistent with the presence of 1 to $2 \mathrm { m } \mathrm { M }$ concentrations of pyrophosphate in $E$ . coli (Kukko & Heinonen, 1982) and in Saccharomyces cerevisiae cells (Navon et al., 1979).
